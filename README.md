## 🚀 Featured Project

### 🔐 Trustworthy Federated Learning Testbed

A reproducible federated-learning research prototype exploring collaborative machine learning when organisations cannot directly share their raw data.

The testbed investigates:

- Non-IID client data
- Intermittent client participation
- Federated averaging (FedAvg)
- Update clipping and Gaussian noise
- Simulated secure aggregation
- Client-level performance and fairness
- Communication cost
- Illustrative privacy-attack evaluation
- Multi-seed experimentation

**Tech:** Python · NumPy · scikit-learn · Federated Learning · GitHub Actions

➡️ [Explore the project](https://github.com/31-prachi/trustworthy-federated-learning-testbed)
